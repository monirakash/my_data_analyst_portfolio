Customer Shopping Behavior Analytics

Python · PostgreSQL · SQL · Power BI

View on GitHub

End-to-end BI solution turning raw shopping data into an interactive dashboard for stakeholder reporting — including customer segmentation and an RFM-lite value analysis.

  • Wrote analytical SQL using CTEs, window functions, ranking, subqueries and aggregations to answer 18 real business questions on revenue, subscriptions, discounts and seasonal demand.
  • Segmented customers into New, Returning and Loyal cohorts.
  • Built a Power BI dashboard with KPI cards, revenue trends, demographics, product performance and dynamic filtering.
  • Automated the workflow from Python cleaning through SQL analysis to the final report.

Python · PostgreSQL · SQL · XPath

  • Designed dimension and fact tables for brands, generics, categories and daily price/stock snapshots.
